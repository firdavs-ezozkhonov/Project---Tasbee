Tasbeeh Counter App

This application is designed as a minimalistic digital counter for repeating phrases and daily practices. Its main purpose is to help the user conveniently 
track the number of repetitions in a modern interface. The design follows a premium minimalistic style and automatically adapts to different screen sizes, 
whether on a phone or a laptop. The app supports both light and dark themes, smooth animations when tapping, and vibration or haptics for a more natural 
interaction. The user can switch between predefined phrases or add their own, with each phrase having its own saved counter. Interaction is kept simple: tapping 
the main button increases the count, a separate button resets it, and arrows allow navigation between phrases. For additional convenience, keyboard shortcuts are 
available, such as Enter or Space to increment, R to reset, and arrow keys to navigate. Technically, the app is built with HTML, CSS, and JavaScript, integrated 
with Cordova to access native features on iOS and Android, and also functions as a PWA with offline support through a service worker. It combines ease of use with 
modern technology, creating a lightweight and reliable tool for everyday practice.

Tasbeeh Counter App
Это приложение создано как минималистичный цифровой счётчик для повторения фраз и ежедневных практик. Его основная цель — помочь пользователю удобно отслеживать 
количество повторений в современном интерфейсе. Дизайн выполнен в премиальном минималистичном стиле и автоматически адаптируется под разные размеры экранов, 
будь то телефон или ноутбук. Приложение поддерживает светлую и тёмную темы, плавные анимации при нажатии и вибрацию или haptics для более естественного взаимодействия.
Пользователь может переключаться между заранее заданными фразами или добавлять собственные, при этом для каждой фразы сохраняется отдельный счётчик. Управление 
реализовано максимально просто: нажатие на основную кнопку увеличивает значение, отдельная кнопка сбрасывает счётчик, а стрелки позволяют переходить между фразами. 
Для удобства предусмотрены горячие клавиши, такие как Enter или пробел для инкремента, R для сброса и стрелки для навигации. Технически приложение построено на HTML, 
CSS и JavaScript, интегрировано с Cordova для доступа к нативным функциям iOS и Android, а также работает как PWA с поддержкой офлайн‑режима через service worker. 
Оно сочетает простоту использования с современными технологиями, создавая лёгкий и надёжный инструмент для повседневной практики.
